# 가족 알림판 (Family Board)

가족 4명(선일·은선·준영·준호)이 일정·리스트·용돈·추억·문서를 함께 나누는 안드로이드 앱.
Jetpack Compose + Material 3, Firebase(Firestore 실시간 공유 + FCM 알림), 자체호스팅 Hermes 릴레이 서버 기반.

- 최초 실행 시 본인 선택으로 사용자 식별 · 현재 버전 **v1.0.116 (versionCode 258)**
- 자세한 개발/빌드/배포는 [HANDOVER.md](HANDOVER.md), 전체 이력은 [CHANGELOG.md](CHANGELOG.md) 참고.

## 주요 기능
- **홈 화면(코르크보드)**: 가족 공지 포스트잇, 일정 보드(지난/다가오는 일정·대상 인원·요일), D-Day 카운트다운, 오늘/내일 날씨(백석동, 최저·최고+아이콘). 새 공지는 가운데로 떠올라 압정이 꾹 찍히는 강조 효과 → '확인' 시 도킹. 표시할 공지가 없으면 일정 보드가 위로.
- **가족 달력**: 월간 보기, 한국 공휴일(대체공휴일·명절), 음력+24절기, 구성원 색상 일정, 연속 다일 일정 막대. 반복 일정(매주·**격주**·매월·매년+음력), 미리 알림(AlarmManager), 드래그로 기간 선택.
- **리스트**: 장보기 / 할 일 / 가족 공지 + 사용자 커스텀 리스트. 담당자 태깅(복수), 작성자 표시. **장보기는 쿠팡·코코달인(코스트코) 상품을 "공유"하면 상품명으로 자동 담김**(출처 배지 직접/쿠팡/코코달인, 링크 탭 시 브라우저 열기).
- **가족 공유 문서함**: pdf·이미지·docx·엑셀 등 업로드 및 다른 앱에서 **'공유'로 저장**. **열람 대상 지정**(기본 모두), 올린이·관리자(선일) 수정·삭제, 최신순, 열 때 '한 번만'.
- **맛집 · 가볼 곳**: 네이버 플레이스 공유 파싱, **AI 추천**(구글 평점+네이버 검증, 최대 5곳, 저장/모두저장), 카테고리·지역 필터, **기본 거리순**(현재 위치 자동 최신화), **길찾기 앱 선택**(T맵·네이버·카카오·구글, 항상), 은선 별점, 댓글.
- **재미진 곳 / 내 재미진 곳**: 유튜브·웹·이미지·영상 공유 게시판. 페이지 방식(이전/다음 + 이어보기), 유형/안 본 필터, 500px 썸네일, 초장문 이미지 타일 뷰어. "내 재미진 곳"은 본인만 조회.
- **가족 사진첩 · 내 사진첩**: 사진을 **촬영일 월별 타임라인**으로 함께 보기(가족 공용) 또는 본인만(내 사진첩). 앱 자체 그리드로 선택(카메라 최근순·빠른 스크롤·년월·중복 자동 제외), 좌우 스와이프·더블탭 확대·❤️·댓글, **월 태그 + 태그 검색**, 사진 이동/복사(두 사진첩 간), **여러 장 선택 일괄 다운로드·공유·삭제**, 회전/공유/다운로드/삭제(올린이·관리자), 홈 "오늘, 그날의 추억".
- **용돈 정산**: 준영/준호 항목 정산·조르기(엄마에게 합계 알림).
- **인생 버킷 리스트**: 부부 공용, 진행 이력·사진.
- **D-Day**: 사용자 D-Day + 가족 생일(매년 자동, 만나이).
- **빠른 연락 요청**: 전체화면 긴급 알림(잠금화면·화면 켜짐·진동) + 위치 공유.
- **알림**: FCM data-only를 Hermes 서버가 릴레이 → 앱이 직접 알림 생성(여러 줄 펼침). 앱 내 업데이트(종 아이콘).
- **삭제 안전장치**: 모든 리스트·보드 항목은 삭제 전 확인 다이얼로그.

## 최근 변경 (v1.0 ~ v1.0.26)
- 앱 이름 **가족보드 → 가족 알림판**, **첫 정식 릴리스 v1.0**.
- **홈 화면 개편**: 대상 인원·요일 표시, 오늘/내일 날씨(백석동), 지난 시간 당일 일정 자동 지난 처리, **새 공지 강조 스포트라이트**(압정 찍힘), 공지 없으면 일정 보드 승격, 오늘 일정 강조.
- **가족 공유 문서함** 신설(업로드/공유 수신/열람 대상/한 번만 열기).
- 맛집·가볼 곳 **AI 추천 5곳**, **기본 거리순 + 위치 자동 최신화**, **"카테고리, 지역/근처" 직접 입력**(근처=반경 600m), 길찾기 앱 선택, 수동 추가 버튼 제거.
- **장보기: 쇼핑 공유 담기** — 쿠팡·코코달인(코스트코) 상품을 공유하면 상품명으로 자동 담김(코코달인은 서버가 product_id로 상품명 조회), 출처 배지(직접/쿠팡/코코달인), 링크 탭 시 브라우저 열기.
- 홈·맛집 스크롤 부드럽게, 일정 삭제 확인, 여러 날 일정 정렬 등.

## 기술 스택
- UI: Jetpack Compose + Material 3, 단일 Activity + Compose Navigation
- 상태: `AppViewModel`(activity 스코프) + StateFlow
- 백엔드: Firestore(익명 인증, 실시간) + FCM(data-only 푸시)
- 서버: 자체호스팅 Hermes(Node/Express + PostgreSQL, Docker) — 알림 릴레이 · 사진/APK 호스트 · 네이버/썸네일 처리
- 영상: media3(ExoPlayer), 이미지: Coil, 날짜: java.time + core library desugaring
