# 가족보드 (Family Board)

가족 4명이 **일정 · 할 일 · 장보기**를 함께 나누는 안드로이드 앱. Family bonding 을 위한 공유 보드.

- 캘린더: 월간 보기 + 한국 공휴일 표시 + 구성원별 색상 일정
- 리스트: 장보기 / 할 일 체크리스트 (공유)
- 최초 실행 시 본인(선일/은선/준영/준호) 선택으로 사용자 식별
- Jetpack Compose + Material 3, Firebase(Firestore) 실시간 공유

자세한 개발/빌드/배포 안내는 [HANDOVER.md](HANDOVER.md), 변경 이력은 [CHANGELOG.md](CHANGELOG.md) 참고.

## 빠른 시작

```bash
./gradlew.bat assembleDebug
```
